## Первый выпуск
- CodeMama ставится в терминал одной командой на Windows, macOS и Linux, без прав администратора. Запуск — `codemama` или коротко `mama`, новая версия — `codemama update`.

## Новое
- Агент ищет по документам Word, Excel и PDF так же, как по коду.
- Читает веб-страницу по ссылке из задачи.
- Файлы в кодировках Windows-1251, KOI8-R, CP866 и UTF-16 читаются без «кракозябр».
- Поиск по проекту встроен: ставить ничего отдельно не нужно.

## Безопасность
- Значения секретов из `.env` агент не показывает и не стирает, если вы сами об этом не попросили.
- Удаление папки не выходит за пределы проекта по ссылкам.

## Улучшения
- На простых задачах агент тратит меньше шагов и токенов.
- Слияние веток, которое вы попросили довести до конца, агент завершает коммитом, а не бросает на полпути.
